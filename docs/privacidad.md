# Política de privacidad: Seguimiento privatizaciones

Esta aplicación es de uso personal de su titular (piedrofederico@gmail.com) y no está abierta a terceros.

- **Qué permiso usa:** únicamente `gmail.send`, para enviar desde la cuenta del titular mails con resúmenes y documentos públicos (Boletín Oficial, CONTRAT.AR) a una dirección fija elegida por el titular.
- **Qué datos lee:** ninguno. La aplicación no lee, guarda ni procesa mails, contactos ni otros datos de la cuenta de Google.
- **Qué datos guarda:** solo el registro de documentos públicos ya revisados, en este repositorio. Las credenciales de acceso se guardan como variables de entorno privadas y no se comparten.
- **Terceros:** no se venden ni se transfieren datos a terceros.
- **Revocación:** el titular puede revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions.

Contacto: piedrofederico@gmail.com
