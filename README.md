# Seguimiento de privatizaciones

Cinco agentes diarios (termoeléctricas de ENARSA, ENARSA, Nucleoeléctrica, CNEA y Carboeléctrica Río Turbio) que revisan el Boletín Oficial, CONTRAT.AR y la prensa, registran cada novedad en `empresas/<empresa>/registro.md` y mandan por mail los PDF de los documentos nuevos.

- Procedimiento: `docs/corrida-diaria.md`
- Reglas y criterios: `CLAUDE.md`
- Credenciales de Gmail: `docs/configurar-gmail.md`
